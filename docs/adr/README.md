# 架构决策记录（ADR）

这里记录**已经落地**的决策：背景、可选项、取舍与后果。只写「做了什么」的设计文档在
《docs/01-架构设计.md》，本目录回答的是「为什么是这样做而不是那样做」。

新增 ADR 的门槛：这个决定半年后还会被人问「为什么」，且换个做法代价很大。
纯实现细节不写 ADR。

| 编号 | 决策 | 影响面 |
|---|---|---|
| [ADR-001](ADR-001-工具调用走定义驱动网关.md) | 工具调用走「定义驱动网关」，不在代码里硬编码分发 | aioa-bridge |
| [ADR-002](ADR-002-工具权限等于用户权限.md) | 工具权限 = 用户权限，Agent 不做二次授权 | agent / aioa-resource |
