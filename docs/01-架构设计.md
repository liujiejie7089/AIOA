## 2. 总体架构（六层）

```
L1 接入层   aioa-shell (Vue3+Vite+TS+Pinia+Element Plus) + wujie 容器 + 子应用(aioa-sdk)
L2 应用层   aioa-server (Spring Boot 3.3 + JDK21)：认证/RBAC/会话/审批/知识库/审计/开放API
L3 中间层   aioa-bridge（Java 模块）：工具注册表 + 工具网关（鉴权/脱敏/限流/熔断/幂等/审计/HITL拦截）
L4 Agent层  aioa-agent (Python：FastAPI + LangGraph)：主agent编排/子agent/HITL挂起恢复/RAG/SSE
L5 模型网关  model_gateway：OpenAI兼容协议，云端⇄本地配置切换，token计量
L6 数据层   PostgreSQL16+pgvector / Redis7 / MinIO
```

主链路：用户提问（带页面上下文）→ `POST /api/v1/conversations/{cid}/runs` → Java 落库返 runId → 前端 SSE `GET /api/v1/runs/{id}/events` → Java 中转 → Python 主 agent 规划 → 子 agent → `POST /internal/v1/tools/invoke` → 中间层 RBAC 二次鉴权+风险判定 →（高风险→HITL 挂起→审批→resume）→ 调业务系统 → 脱敏回流 → 主 agent 反思汇总 → 流式输出 → 落审计。

三条铁律：
1. **SSE 走 Java 中转**，不直连 Python：统一鉴权、统一审计、agent 实现可替换。
2. **发起人身份贯穿全链路**：工具调用必须携带 user_context，中间层二次 RBAC，agent 不能成为越权通道。
3. **traceId / runId / seq 三件套**贯穿前端→Java→Python→业务系统，审计与回放依赖它。

## 4. 中间层（aioa-bridge）

**tool_definition 核心字段**：tool_code(域.动作 UK) / name / description（给 LLM 看，需人工审核）/ version / domain / system_code / endpoint / http_method / input_schema / output_schema(JSON Schema) / risk_level(READ_ONLY|LOW|MEDIUM|HIGH|DESTRUCTIVE) / requires_approval / idempotency_required / timeout_ms / retry_policy / rate_limit / auth_type / auth_ref（密钥走环境变量）/ param_mapping / response_jmespath / max_bytes / status(PENDING_REVIEW→ENABLED，注册默认禁用)。

**三种注册方式**：① Java SDK 注解 `@AioaTool`（starter 启动扫描自动注册）；② REST 注册（HMAC-SHA256 + nonce 防重放）；③ 声明式 YAML 导入。

**调用**：`POST /internal/v1/tools/invoke`（仅内网）——服务 JWT（RS256 短期）+ user_context 二次 RBAC；写操作强制 idempotency_key（Redis SETNX 24h）；Resilience4j 限流熔断（per-tool + per-system）；调用写 tool_invocation_log + audit_log（M3 起哈希链）。

## 5. Agent 运行层

- **主循环**（StateGraph）：perceive → plan → dispatch → execute → reflect → loop/finish；护栏：max_steps=8 / max_tokens / 120s。
- **子 agent = 配置非代码**：agent_definition 表（domain/system_prompt/tool_codes/kb_codes/model_ref/max_steps）。一期 3 个：ticket / dispatch / kb。
- **HITL 状态机**：RUNNING → WAITING_APPROVAL →（APPROVE→RUNNING→SUCCEEDED / REJECT→CANCELLED / 30min 超时→EXPIRED）；LangGraph interrupt + PostgresSaver（thread_id=conversation_id，重启不丢）；恢复前校验 args_hash；支持 args_override（留 diff）。
- **记忆**：短期 = chat_message 最近 10 轮 + 增量摘要；长期 agent_memory 仅留表。
- **SSE 事件**：run.started / run.plan / run.step / agent.switched / tool.called / tool.result / approval.required / approval.resolved / message.delta / citation / need_clarification / message.completed / run.completed / run.failed / error / ping。

## 6. 数据模型（PostgreSQL，约 26 表，全表 tenant_id + deleted_at 逻辑删除）

- 账号权限：sys_tenant / sys_user / sys_role / sys_permission / sys_user_role / sys_role_permission / sys_dept(P1) / sys_login_log
- 接入与会话：app_registry / chat_conversation / chat_message / chat_attachment(P1) / agent_run / agent_run_step / agent_definition / agent_tool_binding
- 中间层：tool_system / tool_definition / tool_permission / tool_invocation_log（只追加，月分区）
- HITL：hitl_approval（args_hash / args_override / expires_at）
- 知识库(M4)：kb_base / kb_document / kb_chunk(embedding vector(1024) HNSW)
- 审计计量：audit_log(prev_hash/hash) / model_provider / model_config / token_usage / openapi_client(P1) / agent_memory(预留)

M1 先建 15 张核心表：sys_tenant, sys_user, sys_role, sys_permission, sys_user_role, sys_role_permission, sys_login_log, app_registry, chat_conversation, chat_message, agent_run, agent_run_step, agent_definition, audit_log, model_provider（其余随 M2/M3/M4 迁移加入）。

## 7. API 总览

- 公共约定：`/api/v1/**`（JWT）· `/internal/v1/**`（Service JWT + 内网）· `/openapi/v1/**`（API Key+HMAC，M4）；统一响应 `{code, message, data, traceId}`；分页 `?page=1&size=20`。
- 契约文件：`docs/04-接口契约/openapi.yaml`（前端⇄Java）、`internal-agent.yaml`（Java⇄Python）。

## 8. 里程碑与门禁

- **M1 骨架（~3周，前端嵌入优先）**：monorepo + Compose 数据件 + shell 登录/菜单/wujie 容器/助手面板（回声）+ 两示例子应用 + Java 认证/RBAC 骨架/15 表 + Python 回声 SSE。
  门禁：① 登录后菜单出现票务/调度且可嵌入操作；② 票务列表页打开助手，上下文栏显示 `app=ticket, page=list`；③ 助手提问 SSE 逐字回声、可中断；④ `docker compose up -d` 一键全绿。
- **M2 核心链路（~4周）**：中间层完整 + 主子 agent + 云端模型 + mock 业务 REST 4~6 个。门禁：真实数据问答、无权 403 留痕、工具失败降级、首字 ≤2s。
- **M3 权限与 HITL（~3周）**：RBAC 完整 + 审批中心 + 审计哈希链。门禁：高风险挂起→批准→生效；驳回无副作用；超时过期；篡改拒绝；哈希链通过。
- **M4 知识库与开放（~4周）**：RAG 引用溯源 + 附件解析 + 双模式切换验证 + /openapi/v1。门禁：20 份文档问答可溯源；断网切本地可用；API Key 调用留痕；全新机器 10 分钟跑起来。

## 9. 风险与对策（摘要）

微前端差异 → AppHost 抽象；双栈运维 → Python 无状态 + OpenAPI 契约 + 统一 traceId；模型切换坑在能力差异 → function calling 白名单 + JSON Schema 强制 + 回归用例集；工具 description 质量 → 审核流 + few-shot + 每子 agent ≤8 工具；上下文膨胀 → jmespath 裁剪 + max_bytes + 摘要；SSE 可靠性 → nginx 关缓冲 + 心跳 + Last-Event-ID；写副作用 → HITL + 幂等键 + 非幂等禁重试；越权通道 → 二次 RBAC + 工具×角色白名单；LangGraph 漂移 → pin 版本 + 门面；范围蔓延 → 锁 26 表 4 里程碑。
