# 24 · 权限审批与组织关联改造 · 一期验收报告

> 依据：`docs/23-权限审批流程与组织关联改造方案.md`
> 范围：**一期 = P2 数据治理（职务字典 + 三口径收敛）+ P1 层级深度（`levels`，迁到一级）+ P4 知会（部分）**
> 结论：**一期已落地并通过全量回归（零回归）**；二期 P3（部门作为申请主体）等未开工。

## 1. 需求 → 实现对照

用户提出三条诉求，一期覆盖前两条的「一级审批」与第②条的前置条件：

| 诉求 | 一期交付 | 验证用例 |
|---|---|---|
| ① 普通用户申请权限，**部门负责人一级审批**即可 | `levels=1` 生效：`timeline` 恰 1 个有效节点，审批人 = 本部门负责人，一级通过即终审（`finalDone=true`） | `e2e_v41_duty_levels` B/E、`e2e_v39_applicant_superior` |
| ① 附带：**一级后上级不再知情** | 引入 `cc` 知会（对标 O2OA「待阅」）：机构管理员进「抄送我的」，不进待办、不阻塞、不可审批 | `e2e_v41_duty_levels` C、`admin_v39_todo_badge` C/D |
| ③ 部门负责人 ↔ 普通用户**关联过少、业务衔接不紧密** | 引入 `org_duty` 职务中间层 + `org_member.duty_code`；「谁是部门负责人」口径由 3 套收敛为 1 套 | `e2e_v41_duty_levels` A/E |
| ② 部门申请权限（向上级审批） | **二期**，未开工 | — |

## 2. 数据治理结果（V42 回填后实测）

| 指标 | 改造前 | 改造后 |
|---|---|---|
| `org_member.duty_code='DEPT_PRINCIPAL'` | 无该字段 | **27 人** |
| `org_department.leader_user_id` 有值 | 8 / 39 | **32 / 39** |
| 持有 `ROLE_DEPT_LEADER` | 3 人 | **28 人** |
| 默认 `PERMISSION_GRANT` 审批链 | 4 级整链（`APPLICANT_SUPERIOR` 无 levels） | **1 级 + `cc:["ORG_ADMIN"]`**（9 个租户） |

**残留缺口（已登记，非回归）**：7 个部门无负责人 —— 3 个为零成员部门（自动跳过）；**4 个有成员但未配负责人**：dept 14 / 21 / 31 / 40。
`e2e_v41_duty_levels` A 段会显式列出，属演示数据待补，不影响改造正确性。

**关键修复**：`superiorLadder` 改「严格模式」解析本部门负责人。修复前，dept 14 成员（无负责人）的审批人被**静默跨部门**指到 dept 11 负责人（uid 7）——把「缺配置」伪装成「能用」；修复后顺延机构管理员（uid 4）并在 `skipReason` 写明「未解析到部门负责人，顺延至机构管理员」。

## 4. 变动清单

### 迁移（**实际版本号与 docs/23 §5 的预测不同**，以目录为准）
| 文件 | 内容 |
|---|---|
| `V41__duty_identity_and_cc.sql` | 建 `org_duty` 职务字典（每租户 4 条）+ `org_member.duty_code/is_primary` + `approval_task.task_role` |
| `V42__backfill_duty_and_one_level_flow.sql` | 三口径回填（只填空值）+ 9 租户 `PERMISSION_GRANT` 默认流改一级 + 知会 |

### 后端
- 新增 `OrgDuty` / `OrgDutyMapper`；`OrgMember.dutyCode/isPrimary`；`ApprovalTask.taskRole`（含 `ROLE_CC` / `STATUS_CC` 常量）。

- `OrgStatMapper`：审批链相关查询统一 `task_role='APPROVE'` 过滤；新增 `selectCcTasksOfUser` / `countMyCcTasks`。
- `WorkflowController`：`scope=cc` 分支 + `summary.cc`。
- `ApprovalFlowProvisioner.DEFAULTS`：`PERMISSION_GRANT` 模板同步为一级 + 知会。

### 前端
- 用户端 H5「待办」页新增第 4 个分区「抄送我的」（带「抄送」徽标；详情提示「无需你审批」）。

### 文档 / 技能
- `docs/23` 追加 §9 实现状态（一期已落地 / 未开工 / 残留缺口）。
- 技能 `aioa-e2e-regression` 更新期望值表与 V41/V42 说明（审批引擎改动必跑清单）。
