## 一、本轮已修复与新增

### 1.1 管理端「系统参数」500 错误 —— 已修复

| 项 | 内容 |
|---|---|
| 根因 | 后端运行的是 **9/9 19:01 构建的旧 jar**，不含 `AdminConfigController`；请求 `/api/v1/admin/configs` 无对应 handler，被当作静态资源解析 → `NoResourceFoundException` → 500 |
| 修复 | 停服 → `./mvnw -DskipTests -pl aioa-resource,aioa-boot -am package` 全量重打包 → 重启；Flyway 已应用 **V18__sys_config.sql** |
| 验证 | `GET /admin/configs` → `code:0, total:14`，四分组齐备 |

**新增能力（V18）**：`sys_config` 表 + `AdminConfigController`

| 接口 | 说明 |
|---|---|
| `GET /api/v1/admin/configs?q=&group=` | 列表（按分组聚合，支持关键字/分组筛选） |
| `PUT /api/v1/admin/configs/{key}` | 更新单参数（类型 + 范围校验） |
| `PUT /api/v1/admin/configs` | 批量更新（逐项校验，返回 changed/rejected） |
| `POST /api/v1/admin/configs/{key}/reset` | 恢复出厂默认 |
| `POST /api/v1/admin/configs/reset` | 全部恢复默认 |

**14 项参数（4 组）**：

- **会话与模型**：单会话上下文轮数上限(10轮)、首字延迟目标(2000ms)、智能体最大推理步数(8)、默认模型路由(auto)
- **额度与计费**：低余额提醒阈值(20%)、每人每日免费词元(20000)、额度提醒开关
- **知识库**：单文件上传上限(50MB)、切片长度(800字符)、检索召回条数(5)、强制引用溯源
- **安全合规**：内容双审开关、留痕保存年限(3年)、强制实名认证

> 参数默认值均取自文档明文（P0 FR-D2 的「默认 10 轮」、FR-F1 的「≤50MB」、FR-G1 的「低于 20% 变色」、4.2 的「留痕 ≥3 年」等）。
> 租户首次读取时自动从平台默认(tenant_id=0)克隆；平台默认缺失则回退代码内置默认表，保证开箱可用。

**管理端新增页面**：`SystemConfigView.vue`（分组卡片 / 搜索 / 待保存计数 / 单项与全部恢复默认 / 变更即审计留痕），路由 `/settings`，菜单「系统参数」。

### 1.2 用户端「会话发起审批」权限引导 —— 已实现

| 场景 | 行为 |
|---|---|
| 有权限（管理员） | 正常提交/通过/驳回，流程不变 |
| 无权限（普通用户） | 捕获 403 → 弹出**权限不足弹窗**（淡色统一样式、手机端居中），文案：**「请联系管理员开通相关权限」**；附「联系管理员」按钮 |
| 联系管理员 | 调 `GET /api/v1/approvals/admin-contacts` 展示同租户管理员账号与昵称 |

**技术实现（`user-client/index.html`）**：

- 新增 `handleApprovalError(e, action)`：统一识别 403 / 权限类文案，401 走登录态
- 新增 `showPermissionDialog(action, detail)`：`perm-modal` 弹窗，复用 `.notif-mask/.notif-modal` 居中体系
- 新增 `showAdminContact()`：展示管理员联系信息
- 新增 `API.adminContacts()`
- 新增 `#i-lock` 图标、`.perm-modal/.perm-ico/.perm-line/.perm-tip` 样式
- 覆盖三处调用点：`submitApproval()`（会话文稿审批）、`submitResultApproval()`（成果审批）、`decideTodo()`（通过/驳回）

**后端新增**：`GET /api/v1/approvals/admin-contacts`（所有登录用户可访问，仅返回用户名+昵称）、`ApprovalOrderMapper.selectTenantAdmins()`。
