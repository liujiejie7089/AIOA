# 90 · 非遗 swagger 接口清单与可用性实测 — 2026-11-20

> 目标：回答「官网域名 + 接口路径能不能拿数据」「有哪些接口可以用」。
> 结论：**能**。外网域名 `https://szbhpt.tsichuan.com/scfy` 的 `/show/*` 免登录可用；
> 接口文档在 `http://192.168.0.205:16060/scfy/v2/api-docs`（比本机 16060 完整）。

---

## 1. 两个服务实例（关键区分）

| 地址 | `/v2/api-docs` | 说明 |
|---|---|---|
| `http://127.0.0.1:16060/scfy` | **404 / `swagger-resources=[]`** | 本机跑的实例，swagger 是空壳；其 Kingbase 数据库间歇性断连 |
| `http://192.168.0.205:16060/scfy` | **200 完整文档**（swagger 2.0「博物馆api文档」） | 内网实例，数据源正常，接口文档齐全 |
| `https://szbhpt.tsichuan.com/scfy` | swagger-ui 200；`/show/*` 200 真实数据 | 公网生产，免登录查询可用 |

**之前"公网 403"是误判**：测的是根路径 `/`（BWS 403）；带 `/scfy/show/...` 路径正常。
后续本机出口 IP 因高频探测（165 次请求）被临时风控返回 403「因权限问题或行为非法，您的访问被拒绝」，
但**服务端出口访问同一 URL 立即返回 200**，证明接口本身可用。⇒ 不要高频刷。

## 4. 对 aios 接入的含义

1. **原 55 个工具覆盖核心域**（项目/传承人/工坊/保护区/旅游），但遗漏了影像展、品牌活动等有真实数据的域。
   已按「code=0 且 data 非空 + 公网抽样」新增 14 个只读接口（见 docs/89 §10），MCP 目录现为 **69 个**。
   未接入的是缓存读写、重复 shopv2、公网无数据的影像明细/抢救性记录。
2. **已切外网域名**：`AIOS_SCFY_BASE_URL=https://szbhpt.tsichuan.com/scfy`，本地 `.env.development`
   与 `start-all.sh` 也已统一，本机 16060 仅排障显式覆盖。这样绕开了本机 Kingbase 间歇断连。
3. **403 不全是频率**：本机 `python-httpx` 默认 UA 会被 WAF 拦（部分路径 403，浏览器 UA 立即 200），
   hub 已加常规 UA/Accept 头；仍**不要高频探测**。
4. **基准要重校**：公网与本机数据有真实差异——公网县域汇总返回省级传承人 6、省级项目 5，
   本机库正常时是 5 / 6；以最终采用的公网数据源为准。
