# 工具注册规范（V1.0 · M2 完整落地，M1 仅骨架）

业务系统把"可被 agent 调用的操作"注册为标准工具。agent 只经中间层（aioa-bridge）发现并调用工具，不直连业务系统。

## 1. 工具元数据（tool_definition）

| 字段 | 必填 | 说明 |
|---|---|---|
| tool_code | ✔ | 全局唯一，`域.动作` 形式，如 `ticket.query_list`、`dispatch.create_task` |
| name | ✔ | 中文名，展示用 |
| description | ✔ | **写给 LLM 看的能力描述**：做什么、参数含义、返回什么、什么场景该调用/不该调用。质量直接决定调用准确率，注册后需人工审核 |
| domain | ✔ | 业务域（= 子 agent 划分）：ticket / dispatch / kb / report … |
| system_code | ✔ | 目标系统编码（→ tool_system） |
| endpoint / http_method | ✔ | 目标 REST 地址与方法 |
| input_schema | ✔ | JSON Schema（Draft 2020-12），同时用于 LLM function calling 与前端参数表单渲染 |
| output_schema | ✖ | 返回结构（建议提供，供校验与文档） |
| risk_level | ✔ | READ_ONLY / LOW / MEDIUM / HIGH / DESTRUCTIVE |
| requires_approval | ✔ | 是否强制人工审批；risk ≥ HIGH 自动 true |
| idempotency_required | ✖ | 写操作建议 true，调用方必须传 idempotency_key |
| timeout_ms / retry_policy | ✖ | 默认 10000ms；**非幂等工具禁止自动重试** |
| auth_type / auth_ref | ✖ | NONE / BASIC / APIKEY / JWT_EXCHANGE / OAUTH2；auth_ref 指向环境变量密钥名，**明文不落库** |
| response_jmespath / max_bytes | ✖ | 大结果裁剪，防撑爆 LLM 上下文 |
| status | ✔ | 注册后默认 PENDING_REVIEW（禁用），管理员审核后 ENABLED |

## 2. 三种注册方式

### 2.1 Java SDK 注解式（自有 Java 系统首选）

```xml
<dependency>
  <groupId>cn.aioa</groupId>
  <artifactId>aioa-tool-sdk</artifactId>
</dependency>
```

```java
@AioaTool(code = "ticket.query_list", name = "查询工单列表", domain = "ticket",
          risk = RiskLevel.READ_ONLY,
          description = "按状态/时间范围/处理人查询工单，返回工单号、标题、状态、创建时间。")
public List<TicketVO> queryList(@ToolParam("状态：OPEN/PROCESSING/CLOSED") String status,
                                @ToolParam("起始日期 yyyy-MM-dd") String startDate) { ... }
```

应用启动时 starter 扫描注解 → 反射生成 JSON Schema → `POST /internal/v1/tools/register`（带系统凭证）→ 状态 PENDING_REVIEW。

### 2.2 REST 注册（第三方/非 Java 系统）

```
POST /api/v1/tools/register
Headers: X-System-Code, X-Timestamp, X-Nonce, X-Signature(HMAC-SHA256)
Body: 完整工具元数据 JSON
```

### 2.3 声明式 YAML 导入（运维/离线系统）

见 `tools/ticket-tools.yaml`、`tools/dispatch-tools.yaml` 样例；启动时自动导入，管理台也支持粘贴导入。

## 3. 风险等级与审批

| 等级 | 含义 | 执行策略 |
|---|---|---|
| READ_ONLY | 查询，无副作用 | 直接执行 |
| LOW | 轻微写（如收藏、备注） | 直接执行 |
| MEDIUM | 一般写（如更新状态） | 直接执行 + 显著留痕；可配置为需审批 |
| HIGH | 重要写（如创建调度任务、对外发送） | **强制 HITL**：挂起 → 人工审批 → 执行 |
| DESTRUCTIVE | 删除/不可逆 | 默认不注册；必须注册时强制 HITL + 双人审批（M3+） |

## 4. 工具描述编写要点（给注册人）

1. 一句话说清"做什么"，一句话说清"什么时候用"；
2. 参数逐个写明含义、格式、可选值；
3. 返回字段列出关键字段名与含义；
4. 提供 3 个 few-shot 示例（examples 字段）：用户问法 → 参数取值；
5. 每个子 agent 绑定工具 ≤ 8 个，超出请拆域。

## 5. 安全约束

- 工具调用以**发起人身份**二次鉴权（tool_permission × 用户角色），agent 不得放大权限；
- 全量调用留痕（tool_invocation_log），参数按 mask_fields 脱敏；
- 密钥只存环境变量/加密列，auth_ref 引用，禁止写进 YAML 或代码。
