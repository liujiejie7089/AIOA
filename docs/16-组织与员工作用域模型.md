# 16 · 组织与员工的作用域模型（V32）

> 本文是「组织与员工」页（`/org-structure`，接口前缀 `/api/v1/org`）的**规格源**。
> 起因：用户实测以租户账号进入该页报 **「部门加载失败 / 员工加载失败 — 403」**。

## 一、缺陷根因（三层口径不一致）

菜单、路由、后端接口对「谁能进这个页」各说各话，形成「进得去页面、接口全 403」：

| 层 | 位置 | 原口径 | 问题 |
|---|---|---|---|
| 菜单 | `MainLayout.vue` `showOrgMenu` | 企业管理员 / 部门负责人 / 成员 / 平台管理员 | 不含租户管理员 |
| 路由 | `router/index.ts` `minTier: 'org'` | tier 0（最低门槛） | 租户管理员（tier 1）、平台管理员（tier 2）都能进 |
| 后端 | `OrgGuard.requireOrgUser` | 仅机构成员 | **不认租户管理员，也不认平台管理员** |

另有一处放大：租户管理员在 `org_member` 里**没有成员行**，故 `requireInstitutionId()` 直接抛
「当前账号未绑定任何机构」。实测 9 个租户中 **8 个**（tenant 2/4/5/6/7/8/9 的纯租户管理员）
+ 平台管理员 `admin` 全部 403；只有「租户管理员恰好兼任机构管理员」的 tenant 3 侥幸正常。

## 二、修复后的三级作用域

| 角色 | 可读范围 | 可写范围 | 机构选择器 |
|---|---|---|---|
| 机构成员（企业管理员 / 部门负责人 / 成员） | 本机构（**硬绑定**） | 企业管理员可写本机构 | 隐藏（仅一家） |
| 租户管理员 | 本租户全部机构（可切换） | 本租户全部机构 | 显示 |
| 平台管理员 | 跨租户（运维视角） | **只读** | 显示 |
| `ROLE_USER` 等无机构角色 | — | — | 403 |

判定唯一落点：`OrgGuard.resolveScopeInstitution(requested)`。

```
机构成员  → 返回本机构；入参指向他机构一律 404（不泄露存在性）
租户管理员 → 入参须属本租户；未传则取本租户首个启用机构
平台管理员 → 入参任意启用机构；未传则取全局首个启用机构
其他       → 403「当前账号未绑定任何机构」
```

## 三、接口契约

| 接口 | 说明 |
|---|---|
| `GET /org/institutions` | 返回 `{items, total, canWrite, boundInstitutionId, scope}`；`scope` ∈ `ORG`/`TENANT`/`PLATFORM`，供前端渲染机构选择器与按钮显隐 |
| `GET /org/departments?institutionId=` | 部门树；`institutionId` 可选 |
| `GET /org/members?institutionId=` | 员工名册；`institutionId` 可选 |
| `POST/PUT/DELETE /org/departments[/{id}]`, `/members[/{id}]`, `/members/import` | 写接口，`requireOrgWriter()` = 企业管理员 或 租户管理员；`institutionId` 可选 |
| 其余 `/org/**` 读写 | 同样接受可选 `institutionId`，读走 `requireOrgUser()` |

**写入范围**：平台管理员**不**参与企业组织的日常维护（只读运维视角）。
理由是「租户管理员端管资源与规则、企业管理员端管组织与执行」的范围纪律，
而平台管理员连租户都不是——其职责是租户/套餐/全局配置。

## 四、前端行为

- 页面挂载时**先**取 `GET /org/institutions` 解析作用域，再拉数据；
  返回空机构时走 `el-empty` 空态提示，而不是弹两条 403 错误横幅。
- `instOptions.length > 1` 显示机构选择器；只有一家时显示机构标签。
- `canWrite=false` 时隐藏「新增部门 / 加下级 / 编辑 / 删除 / 新增员工 / 导入 / 假期」，
  并显示「只读：组织维护由企业管理员执行」。
- 所有 `/org/*` 调用都带 `institutionId`，保证切换机构后各区块数据同源。

## 五、回归

- 接口层：`scripts/e2e_v32_org_scope.py`（A 组 15 条覆盖读作用域与越界、B 组 5 条覆盖写作用域）。
- 渲染层：`scripts/check_org_structure_render.py`（4 类角色 × 无 403 / 有数据 / 选择器与按钮显隐）。

## 六、已知取舍

- 机构编码在租户内唯一且**注销不释放编码**（保留法人档案），因此回归脚本每轮用带序号的编码，
  并按 `E2E-V32%` 前缀清理历史测试机构。
- 机构成员传入他机构 `institutionId` 返回 404 而非静默回退本机构：静默回退会让调用方误以为
  操作作用在目标机构上，属更危险的失败模式。
