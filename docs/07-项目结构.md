# AIOA 智能办公基座 · 项目结构文档

> 版本：M1 骨架（一期）
> 最后更新：2026-09-07
> 配套说明：架构设计见《01-架构设计.md》、接口契约见《04-接口契约/》、部署见《05-部署手册.md》

本文档描述仓库（monorepo）的完整目录结构、各模块职责与关键文件，供开发者快速建立全局认知。

---

## 1. 顶层结构

```
aioa/
├── docs/                  # 设计文档与契约（架构/接入规范/工具注册/接口契约/部署/借鉴说明）
├── deploy/                # 私有化部署件：docker-compose + nginx + Dockerfile + .env
├── web/                  # 前端：pnpm workspace（主应用 + 示例子应用 + 接入 SDK）
├── server/               # 后端：Maven 多模块（Spring Boot 3.3 + Java 21）
├── agent/                # Agent 服务：Python（FastAPI）
├── .tools/               # 本地工具链（Maven 启动器，不入库核心逻辑）
├── .gitignore
├── README.md             # 仓库总说明与快速启动
└── .workbuddy/           # 工作记忆与任务（非交付物）
```

> 说明：`.tools/` 仅含本地 Maven 启动器 `mvnw.sh`（系统 mvn 不可用时的替代），运行产物（`target/`、`dist/`、`.venv/`、`node_modules/`）均被 `.gitignore` 排除。

## 2. 后端（server/，Java 21 + Spring Boot 3.3）

Maven 多模块，`cn.aioa` 统一 groupId，父 pom 为 `aioa-server`（packaging=pom）。

```
server/
├── pom.xml                     # 父 pom：模块声明 + 依赖版本管理（lombok 全局 provided）
├── aioa-common/                # 基础层：响应体 / 异常 / TraceId / jsonb 类型处理器
│   └── src/main/java/cn/aioa/common/
│       ├── resp/ApiResponse.java        # 统一响应 {code,message,data,traceId}，code=0 成功
│       ├── resp/PageResult.java         # 分页包装
│       ├── exception/BizException.java   # 业务异常 + 静态工厂(unauthorized/forbidden/notFound/badRequest/notImplemented)
│       ├── web/GlobalExceptionHandler.java  # @RestControllerAdvice 统一异常处理（不含 401/403）
│       ├── trace/TraceId.java / TraceIdFilter.java  # MDC 链路追踪
│       └── mybatis/AbstractJsonbTypeHandler.java + JsonbMap/List 变体  # pg jsonb 读写
├── aioa-security/              # 安全层：JWT 用户令牌 + 服务令牌 + Security 配置
│   └── src/main/java/cn/aioa/security/
│       ├── JwtTokenProvider.java         # 用户侧 JWT（HS256，access 2h/refresh 7d）
│       ├── JwtAuthenticationFilter.java   # /api/** Bearer 认证
│       ├── AuthUser.java / AuthUserContext.java  # 登录用户上下文（ThreadLocal）
│       ├── ServiceTokenProvider.java / ServiceTokenFilter.java  # 服务间令牌（/internal/**）
│       ├── JwtProperties.java / ServiceJwtProperties.java       # 配置绑定
│       └── SecurityConfig.java           # 放行/认证/服务令牌三档路由
├── aioa-admin/                # 账号 / RBAC / 应用注册表
│   └── src/main/java/cn/aioa/admin/
│       ├── entity/    # SysUser/SysRole/SysPermission/SysUserRole/SysRolePermission/SysTenant/SysLoginLog/AppRegistry
│       ├── mapper/    # 上述 8 张表的 MyBatis-Plus Mapper
│       ├── service/   # AuthService（登录/刷新/me）、AppService（enabled 应用）、AdminQueryService
│       └── controller/# AuthController（login/refresh/me/menus）、AppController（/apps）、AdminController（用户/角色/权限列表）
├── aioa-chat/                # 会话与 Agent 运行（SSE 中转 Python）
│   └── src/main/java/cn/aioa/chat/
│       ├── entity/    # ChatConversation/ChatMessage/AgentRun/AgentRunStep
│       ├── mapper/    # 对应 Mapper
│       ├── dto/       # 请求/响应模型（CreateConversationRequest/CreateRunRequest/AgentRunRequest/AgentUserContext/RunCreatedResponse）
│       ├── service/   # ConversationService（CRUD）、RunService（发起 run + SSE 转发）
│       ├── config/    # AgentProperties、ChatConfig（WebClient 调用 Python）
│       └── controller/# ConversationController、RunController（runs 事件流 + 取消）
├── aioa-bridge/              # ★ 中间层：工具注册表（M1 占位，M2 完整实现）
│   └── src/main/java/cn/aioa/bridge/
│       ├── entity/    # ToolSystem/ToolDefinition/ToolPermission/ToolInvocationLog（数据模型已建）
│       ├── mapper/    # 对应 Mapper
│       └── controller/InternalToolController.java  # POST /internal/v1/tools/invoke → 501 占位
├── aioa-tool-sdk/            # 子应用接入 SDK 契约（M1 占位）
│   └── src/main/java/cn/aioa/tool/sdk/PageContext.java  # 页面上下文快照（Lombok）
└── aioa-boot/               # 启动模块（聚合所有能力）
    └── src/main/java/cn/aioa/boot/
        ├── AioaBootApplication.java     # @SpringBootApplication，扫描 cn.aioa
        ├── config/MybatisPlusConfig.java / OpenApiConfig.java
        ├── runner/StartupCheckRunner.java  # 启动自检
        ├── resources/application.yml       # 端口/数据源/redis/jwt/agent base-url
        └── resources/db/migration/
            ├── V1__init.sql   # 15 张核心表（统一含 tenant_id/时间戳/逻辑删除）
            └── V2__seed.sql   # 种子：租户/角色/用户admin/权限/app_registry/agent_definition/model_provider
```

**模块依赖方向**：`boot` → 依赖全部业务模块；业务模块 → 依赖 `common` + `security`；`bridge`/`chat` 额外依赖 mybatis-plus。`common` 保持轻量（不依赖 security，避免循环）。

## 3. 前端（web/，pnpm workspace + Vue 3 + Vite 6 + TS）

```
web/
├── package.json / pnpm-workspace.yaml / tsconfig.base.json   # workspace 根配置
├── apps/
│   ├── shell/                   # 主应用：统一工作台（Vue3 + Element Plus + wujie-vue3）
│   │   ├── src/
│   │   │   ├── main.ts / App.vue
│   │   │   ├── router/index.ts           # 登录守卫 + 路由（login/home/app/:appCode/approvals/kb/admin）
│   │   │   ├── layouts/MainLayout.vue    # 顶栏 + 左侧菜单 + 右侧 AI 助手抽屉 + 内容区
│   │   │   ├── views/                    # Login/Home/AppHost(子应用容器)/Approvals/Kb/Admin
│   │   │   ├── components/assistant/      # AssistantDrawer(对话)/ContextBar(上下文)/ConversationList/MessageList
│   │   │   ├── micro/bridge.ts           # 监听子应用 postMessage（AIOA_SET_CONTEXT/OPEN_ASSISTANT/NOTIFY）
│   │   │   ├── stores/                   # Pinia：auth / apps / assistant
│   │   │   ├── api/                      # axios 实例 + auth/apps/conversations/runs 封装
│   │   │   └── types/index.ts
│   │   └── vite.config.ts                # devServer proxy /api → :8080
│   ├── demo-ticket/              # 示例子应用：票务（wujie 标准接入）
│   │   └── src/ views/TicketList.vue / TicketDetail.vue、data/tickets.ts、aioa.ts（引 @aioa/sdk 上报上下文）
│   └── demo-dispatch/            # 示例子应用：统一调度（iframe 模拟遗留系统，不引 SDK）
│       └── src/ App.vue（调度任务列表 + 新建对话框）
└── packages/
    └── aioa-sdk/                 # @aioa/sdk：子应用接入 SDK（框架无关 TS 库）
        └── src/
            ├── types.ts / protocol.ts    # PageContext 等类型 + postMessage 协议常量
            ├── bridge.ts                 # createAioaBridge({appCode}) 单例
            └── index.ts                 # 导出 setContext/getContext/openAssistant/onAction/notify/getToken
```

**关键约定**：
- 主应用端口 5173，票务子应用 5174（wujie），调度子应用 5175（iframe）。
- 子应用通过 `postMessage` 向主应用上报 `PageContext`（appCode/page/filters/entity 等），主应用右侧助手抽屉据此展示"在哪问就答哪"。
- `@aioa/sdk` 在非工作台环境（`window===window.parent`）全部 API 降级 no-op。

## 4. Agent 服务（agent/，Python 3.13 + FastAPI）

```
agent/
├── pyproject.toml               # 依赖：fastapi / uvicorn / pydantic / pyyaml / httpx（M1 不引 langgraph）
├── README.md
├── app/
│   ├── main.py                  # FastAPI 实例 + /health + /internal/v1/runs + 全局异常
│   ├── config.py                # 环境变量（SERVICE_JWT_SECRET / AIOA_SERVER_BASE_URL / MODEL_DEFAULT / PG_DSN）
│   ├── schemas.py               # RunRequest / PageContext / UserContext / SseEvent
│   ├── core/
│   │   ├── runtime.py           # ★ 门面 async run(req) -> AsyncIterator[SseEvent]（M1 委托 echo，M2 换 graph）
│   │   ├── echo_runtime.py      # M1 回声：逐字符推送 message.delta
│   │   ├── events.py            # SseEvent → SSE 帧（id/event/data）序列化
│   │   └── guards.py            # 护栏：MAX_TEXT_LEN / MAX_WALL_TIME
│   ├── model_gateway/
│   │   ├── gateway.py           # 模型网关桩：resolve(model_ref)；echo 可直接用
│   │   └── providers.yaml       # echo/qwen-cloud/deepseek/local-vllm/local-ollama（双模式切换）
│   └── tools/
│       └── gateway_client.py    # 工具调用桩：invoke_tool() 抛 NotImplementedError（M2）
└── tests/
    └── test_echo_run.py         # pytest：验证事件序列 + 回显一致性（3 passed）
```

**事件协议**（与 `docs/04-接口契约/internal-agent.yaml` 一致）：
`run.started` → `message.delta`（×N）→ `message.completed` → `run.completed`，帧格式 `id/event/data`，seq 单调递增。

## 8. 常用命令

```bash
# 后端编译打包
cd server && ../.tools/mvnw.sh -q -DskipTests package

# 前端安装与构建
cd web && pnpm install && pnpm -r build

# Agent 测试
agent/.venv/Scripts/python.exe -m pytest agent/tests -q

# 一键部署
cd deploy && cp .env.example .env && docker compose up -d
```

详见 `README.md` 第 3 节「快速启动」。
