用户报 4 问题（截图：`GET /aios/api/v1/asr/status` → 401，请求头无 Authorization）。代码侧证据链：

- **① 401 根因 = 手机端未登录**：`user-client/index.html` `req()`（2812-2815 行）只在 `state.token`

  SecurityConfig `anyRequest().authenticated()`，401 JSON 带 traceId = 安全链正常。
- **② 语音 = ① 的下游 + ASR 模型独立缺口**：模型 483MB 不进镜像不进 git（.gitignore），
  agent 挂卷 `../agent/.models:/app/.models:ro`（compose 377 行）；fresh clone 后目录空 →
  Docker 静默建空目录 → `engine.py status()` available=false → 503 → H5 麦克风置灰。
  开发机 `D:\aios\agent\.models\small\` 四文件齐全（model.bin 483MB）⇒ 可作搬运源。
  交付方案：登录 → 验 status → 缺模型则 tar+scp 搬运 → restart agent。
- **③ `Invalid character [0x05 0x01 0x00]`** = SOCKS5 握手字节打到 Tomcat 8080（内网扫描器
  垃圾流量），无害噪声；可选加固 = 10.0.0.3:8080 防火墙仅放行隧道机 219.151.186.24。
- **④ `aios-server: command not found`** = 用户把 `docker compose logs` 的日志行粘进 shell
  执行；正确姿势 `docker compose logs -f server`。
