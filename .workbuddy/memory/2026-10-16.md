## 补：Java 状态流转单测（`01d8dbd`）

上面那条「Java 侧运行时行为只有读码佐证」的缺口已补上，且**不是靠读码补的**：
`server/aioa-chat/src/test/java/cn/aioa/chat/service/RunServiceHitlTest.java`（纯 JUnit5 + Mockito，
不起 Spring、不连 DB；`forward`/`completeRun` 是 private，反射调用）。
- T1 暂停不被当完成（落 `WAITING_INPUT`、**不存在**任何 status=SUCCEEDED 的 patch、不落 assistant 消息、不计费）
- T2 `subscribe(WAITING_INPUT)` → `verifyNoInteractions(agentWebClient)`（一条 agent 请求都没发）+ 下发 `code=WAITING_INPUT`
- T3 `resume` 非 `WAITING_INPUT` 抛 `BizException` 且不打 agent

运行：`./mvnw -pl aioa-chat -am test -Dtest=RunServiceHitlTest -DfailIfNoTests=false -Dsurefire.failIfNoSpecifiedTests=false`
（**`-Dsurefire.failIfNoSpecifiedTests=false` 是必需的**，否则 `-am` 会把无匹配用例的兄弟模块也判失败）
→ `Tests run: 4, Failures: 0, Errors: 0, Skipped: 0 / BUILD SUCCESS`（我本人复跑过一次）。
