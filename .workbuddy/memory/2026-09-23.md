### 结构（17 个源文件 + 3 个测试类）

| 层 | 类 | 职责 |
|---|---|---|
| 契约 | `ScfyParam` / `ScfyEndpoint` / `ScfyCatalog` | 56 可用 + 11 废弃，唯一事实源 |
| 事实源 | `core/ScfyEnums` | 等级/市州枚举，取值全部来自实测 |
| 适配器 | `adapter/ScfyClient`（+`ScfyResponse`/`JsonNodes`） | JDK HttpClient，**只发 GET，无写方法** |
| 校验器 | `validate/ScfyParamValidator` | 未知参数/必填/枚举/范围 + 缺参追问话术 |
| 工具层 | `tools/Scfy{Inheritor,Project,Shop,Ecology,Travel}Tools` | 56 个 `@AioaTool`（9+8+13+12+14） |
| 装配 | `ScfyAutoConfiguration` | 开关 + 启动一致性自检 |

### 关键设计决策（后续别推翻）

1. **`enabled` 默认 false**：不给配置 = 不注册任何工具、模型能力清单里不出现。可插拔落在这里。
2. **适配器只提供 GET，没有写方法** —— 把「只读」落成类型系统里「不存在」，比落成「记得别调」可靠。
3. **一致性自检**：`@AioaTool` 是编译期注解、无法引用运行时 `ScfyCatalog`，
   两处文本必然重复 ⇒ 启动时用反射对账，工具引用了不存在/已废弃接口**直接抛异常阻止启动**，
   契约有接口但没工具只告警（分阶段接入的正常态）。
4. **校验器的目标是「拦住会静默出错的调用」**，不是「校验合不合法」：
   市州全称（返回 0 条）、未知参数名（shopId 而非 id）、level≠country（传了等于没传）三类必须拦。

用户问：域名下拼别的业务路径，还能不能查到数据。**结论：不能 —— 全域唯一匿名可查入口就是 `/scfy/show/*`。**

- `/` → 403（BWS）；`/scfy`（无斜杠）→ **502 `upstream connect failed os error 10061`**（该精确路径被网关转发到一个已宕上游）；`/scfy/` → 500 `code=401 Token失效`。
- `/scfy/show/ecologicalArea/getAreasNum` → 200 `code=0 {country:1, province:6}`；`/scfy/show/project/getProjectCountByArea?area=成都市` → 200 且含 **联合国教科文组织 num=1**（坐实 `level` 枚举必须含 `un`）；`/scfy/show/travel/getRoutesTopFewList?topNum=3` → 200 真实数据。
  ⇒ **放行规则精确作用在 `/show/**`**，不是整个应用免登录。
- 文档里出现过的其他业务前缀 `/web/api`、`/zytf/api`、`/nmch/ccss`、`/applet/*`、`/sys`、`/sso`、`/scfy-zigong/`、`/api/*`、`/portal/` —— **一律 BWS 404，一个都没部署在这个域名上**。`/show/*`（去 `/scfy` 前缀）也 404。
- `/scfy/swagger-ui.html` → 200（只有静态壳）；但 `/scfy/v3/api-docs`(+`swagger-config`/`default`/`?group=`) 与 `/scfy/actuator/health` → **500 `code=401` 被 Shiro 拦** ⇒ 线上接口清单**不可匿名获取**。
- `http://szbhpt.tsichuan.com:16060/*` → 502 `os error 10061`（**死代理**）；https:16060 → Tunnel 502。
  ⇒ 16060 与 443 域名是**两条独立链路**：域名由 BWS 在 443 终结转发；16060 是对方机器上另一个已死上游。「本地 16060 测试环境」≠「生产 16060」。

**一次失败的方法（已登记，勿重蹈）**：想用「模块名 × 假方法名」形态差异枚举未文档化模块 —— **不成立**。
基线校准：「已知存在模块 `project` + 假方法」与「已知不存在模块 `zzznope_xyz` + 假方法」返回**完全相同的 `APP_404`**，
该应用对任何未映射路径统一回 404，无法区分。脚本 `_probe_fy_show_modules.py` 的「全部存在」是**假阳性，不采信**。
⇒ **模块边界只能以接口文档为准**；「是否存在文档外模块」当前无法证实也无法证伪，属认知边界，不当结论。
