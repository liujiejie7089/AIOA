
## 企微工具 5 → 23 + 三处根修（docs/64 §9.10）

- **`_since()` 7 天边界是真 bug**：`begin=now-7d` 截秒 + 子进程/网络延迟 ⇒ 必然比服务端 168h
  下界老 1~3 秒 ⇒ `850016 begin_time不能早于7天前`。修：`_BEGIN_MARGIN=1h`。
  二分实测：now=11-02 17:55 时，`10-26 15:55`/`17:55` 失败、`18:10` 通过。
- **`40073 非法的 chat_id` = 模型拿群名当句柄**。修两层：agent `_tool_digest` →
  `tool_calls_log[].digest`（600 字符）→ Java `RunService.formatToolDigest`（240）随历史回灌；
  `session_messages`/`message_send` 允许传群名，内部用最近 7 天会话解析。
- **CLI 业务错误是 exit 0 + `{"error":...}`**，不是非零退出 ⇒ 必须 `_call()` 拦，否则
  「成功返回 0 条」。这条坑很容易复现。
- **会话丢失**：`conversationId` 只在内存。H5 加了 `aios_oa_last_conv` / `aios_last_conv`
  两套记忆（按 账号+项目+对象，7 天），三样对上才恢复。
- **`agent_run_step` 终于有写入方**：`RunService.persistToolSteps`，凭据键打码。
- **日历/会议不能用 `_since()`**（它夹 7 天）⇒ 新增 `_range_forward()`（现在 → +30 天）。
- **`_ok()` 剔除 `security_notice` / `extra_identity_context`**：CLI 每包都带，官方禁止外传。
- **工具数快照在 `mcp_server_tool`（不是 mcp_tool）**，需 hub 重启后重新 trust 才会从 5 变 23；
  `scripts/_verify_mcp_registry.py` 的 EXPECT_TOOL_COUNT 已同步。
- 验收：argv 哨兵 47 项全绿 · agent pytest 232 passed · aios-chat 编译通过 ·
  真实凭据离线实测 session_messages("成都易构") 7 条。
