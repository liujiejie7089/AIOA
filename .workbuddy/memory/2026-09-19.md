### 关键经验（重要，写后续套件必读）
1. **管理端按钮级测试必须逐角色分进程跑**：单浏览器连续全量重载 20+ 路由、点击上百按钮，
  会触发 Edge renderer 资源耗尽型挂起（某路由 `page.goto` 无限阻塞，`set_default_navigation_timeout`
  都不触发）。逐角色独立子进程 + 独立浏览器是唯一稳定解。
2. **挂起排查方法论**：先 `taskkill /F /IM msedge.exe` 清残留 headless 进程；
  Git Bash 的 `ps`/`tasklist` 输出可能是**陈旧缓存**，务必用 PowerShell `Get-CimInstance`
  看真实进程状态；`msedgewebview2.exe` 是 IDE 自身的，勿杀。
3. **稳定导航三板斧**：`page.goto(wait_until="commit")`（不等待 DOM/网络空闲，避免 busy 渲染挂起）+
  越权断言用 `page.url`（Python 侧缓存值，无渲染往返，替代会挂起的 `page.evaluate(location)`）+
  按钮枚举用**单次** `page.evaluate` 快速返回（替代逐元素 bounding_box 往返，慢 50 倍）。
4. **点击兜底**：`locator.click(timeout=2000, no_wait_after=True, force=True)` + 每次点击后 `Escape`
  关闭可能弹开的 dialog/drawer，避免遮罩级联影响后续点击。
5. **跳过清单取舍**：只跳「破坏性/改真实数据/触发真实 AI 或外部平台调用」的按钮
  （删除/退出/保存/提交/通过/驳回/解绑/初始化/校准/同步/立即执行/生成/导入导出等），
  其余一律点；空文本按钮（树展开箭头）也要跳过（触发 el-tree 重渲染）。跳过清单过宽会
  导致「点 0 个」失去测试意义，过窄会挂起。

## 本地开发 / 生产两套环境变量（产出 `deploy/.env.development` + `.env.production` + `ENV.md`）

**做法**：先扫全仓把环境变量收全（`application.yml` 的 `${...}` 占位 + 各模块 `.env.example` +
`docker-compose.yml` + `agent/app/config.py`），**不凭空造键**；两份文件**键集合与键序完全一致**
（77 项，`diff` 为空），可直接逐行对照。

**★ 踩到的真 bug（值得记住）**：`set -a && . env文件` 时，含 **空格 / `&` / `<` `>` / `*`** 的
值会被 shell 当**运算符**——`&`=后台、`<`=重定向、空格=分词 ⇒ **整份文件解析中断**。
实测生产文件只加载了 **4/78** 个键（`SPRING_DATASOURCE_USERNAME=<db-user>` 直接 syntax error）。
修法 = 这些值**一律加双引号**（docker compose `--env-file` 也会正确剥引号）。
涉及键：`SPRING_DATASOURCE_URL`(含 `&`)、`*_SCOPE`(含空格)、`*_SYNC_CRON`(含空格与 `*`)、
`<db-user>`/`<gitee-org>`/`<path-to-truststore>`/`MODEL_DEFAULT=<a|b|c>`。

**验证手段（可复用）**：① 键序 `diff <(grep -oE '^[A-Z_]+=' A) <(grep -oE '^[A-Z_]+=' B)`；
② 重复键 `sort | uniq -d`（首版真踩到 `AIOA_KB_STORE` 在 §0 与 §7 各声明一次）；
③ **实测 source 后数 `env` 导出键数 + 报错行数**，并回读被引号救回的值；
④ 生产模板自查 `grep DEV_ONLY__`（应为 0，命中只允许在占位约定注释里）。

**约定**：`CHANGE_ME__xxx`=必须替换的敏感值 · `DEV_ONLY__xxx`=仅本地 · `<xxx>`=按实际填 ·
留空=能力未启用。**前端 env 单独一档**（vite 只读各应用自己的 `.env`，写进 `deploy/.env` 无效），
已在 `ENV.md` §4 单独列表。`.gitignore` 加 `!deploy/.env.development` / `!deploy/.env.production`
例外让两份**只含占位值**的模板入库。
