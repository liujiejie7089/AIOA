### ① 管理端「新增机构」后不显示

**根因（数据级，铁证）**：`org_institution` 里存在 `id=87, code='ttt', tenant_id=0`。
平台管理员（`ROLE_ADMIN`）的 `tenantId` **恒为 0**（平台自身租户），而
`InstitutionService.create` 用的是**裸** `actor.getTenantId()`，
列表/详情用的是 `OrgGuard.resolveRequestTenant(u)`（平台管理员→「机构最多的启用租户」= 2）。
⇒ 建出来的机构挂 tenant 0，**任何租户的列表都查不到它**。

同一文件里 4 处都犯了这个错：`create` / `update` / `changeStatus` / `assignAdmin`（行 118/167/216/250）。

**修复**：4 处统一改为 `guard.resolveRequestTenant(actor)`。
**数据修复**：`V64__fix_institution_tenant_scope.sql` 把 `tenant_id=0` 的存活行回填到默认租户（=2）。

> ⚠️ **V64 第一版直接挂**：`UPDATE org_institution SET tenant_id=(SELECT ... ORDER BY (SELECT COUNT(*) FROM org_institution ...))`
> ⇒ MySQL **Error 1093**「You can't specify target table for update in FROM clause」。
> 正解：先 `CREATE TEMPORARY TABLE` 算好目标租户，再让 UPDATE 只读临时表。
> 且失败后必须清 `flyway_schema_history` 里 `success=0` 的那行，否则后续迁移全被挡。

### ② 资源与授权管理「停用」无效

**根因**：前端 `toggleGrant(id)` → `POST /tenant/grants/{id}/toggle` **不带 body**；
后端 `TenantAdminController` 写的是
`boolean enabled = body == null || !Boolean.FALSE.equals(body.get("enabled"))`
⇒ `body == null` 恒等于 `enabled = true` ⇒ **点「停用」永远变成「启用」，记录永远是已启用**。

**修复**：
- 后端：不传 `enabled` 时**真翻转**（`explicit != null ? explicit : !TRUE.equals(g.getEnabled())`），
  显式传值仍按值设置（幂等）。
- 前端：`toggleGrant(id, enabled)` **显式传目标状态**（`!isOn(row)`），避免依赖后端默认值与连点抖动。
- 补成功回执（此前静默成功，用户无法区分「生效了」和「没反应」）。
- 错误文案：业务失败是 HTTP 200 + `code≠0`（异常体是 `ApiError`，**没有 `.response`**），
  原写法 `e.response.data.message` 永远取不到 ⇒ 统一走 `errText()`。

### ③ 用户端经营数据展示不协调

截图形态：标题「近 6 个月销售额趋势」，下面**两块满宽色板**，轴标签「1月」「2」。
库内 `biz_kpi_trend` 只有 2 行（`tenant_id=0`，`point_label` = `1月` / `2`，值都是 4.00）。

**五个成因**：
1. **柱高算 70px，容器可用高度只有 `74-18=56px`** ⇒ 柱顶顶穿到标题上。
2. `.bar{flex:1}` ⇒ 只有 2 个点时每根占半屏 ⇒ 变成两块色板。
3. 标题**写死**「近 6 个月」，与真实点数无关 ⇒ 标题本身在传达错的事实。
4. 轴标签半带单位（管理端自由文本填了「1月」和「2」）。
5. 涨跌配色是**欧美口径**（`.delta.up→绿 / .down→红`），与项目既定的中国口径（涨红跌绿）相反。

**修复**（`user-client/index.html`）：
- `.bars` 高度 74→100px（70 柱 + 12 数值 + 18 轴标签）、`justify-content:center`；
  `.bar{flex:1 1 0;max-width:34px}` ⇒ 点少时是「几根柱」而不是「几块板」。
- 每根柱加数值标签 `<i>`（此前趋势完全不可读）。
- 标题动态：`近 N 个月销售额趋势`。
- 轴标签口径统一（`axisLabel()`：月口径下纯数字补「月」）。
- `.delta.up→红 / .delta.down→绿`。

**遗留（未动，属产品决策）**：`biz_kpi` / `biz_kpi_trend` 仍是 `tenant_id=0`
（`AdminKpiController` / `KpiController` 都用裸 `user.getTenantId()`，`aioa-resource` 无 OrgGuard）。
**没有跟着回填**，因为一旦回填，平台管理员当前能看到的看板会立刻变空（读侧也读 0）；
要修得先给该页加租户选择器。已作为开放项记录，不在本轮擅自改。
