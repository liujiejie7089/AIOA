## 生产入口 404 定性：网址少结尾斜杠，卡在隧道机 openresty

用户截图：`https://mall.egoaicloud.com/aios/web`（**无结尾斜杠**）→ 404，
响应体是 openresty/1.27.1.2 自己的错误页 ⇒ 请求没到 AIOS 后端。
根因：隧道机 openresty 与项目自带入口配置（`deploy/nginx/aios-entry.conf`）
同样是 `location /aios/`（带斜杠前缀），匹配不到 `/aios/web` 这种无斜杠形态
⇒ 落默认 404。**不是这次部署改坏的，是该配置的固有形态**。

- 立即解：用规范地址（带斜杠）`https://mall.egoaicloud.com/aios/web/`、`/aios/h5/`；
  后端侧两种形态都应 200（Spring 尾斜杠等价匹配 + SecurityConfig 白名单
  `/aios/web/**` 与 `/aios/web` 两种都放了，见 `aioa-server` 时代沿用的写法）。
- 根治（需机房/运维改隧道机，agent 够不着 219.151.186.24）：加两行 exact location
  **302 跳转到带斜杠规范地址**——
  `location = /aios/web { return 302 /aios/web/; }` / `location = /aios/h5 { return 302 /aios/h5/; }`。
  ⚠️ 必须是 302，不能改成 `location /aios` 无斜杠前缀直接反代：管理端 SPA base 是
  `/aios/web/`，地址栏停在无斜杠形态会导致 vue-router 落在 base 之外 ⇒ 白屏
  （aios-entry.conf 文件头 ① 有完整论证）。
