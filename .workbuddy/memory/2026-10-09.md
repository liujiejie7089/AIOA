## 四、踩坑 / 结论

- **`BizException` 无 `conflict()` 工厂**：409 一律写 `new BizException(409, "...")`（本仓约定，`PmProjectService`/`PmProjectMemberService` 同款）。
- **`PmDocService` ↔ `PmProjectService` 不能互相注入**（会成环）：立项建目录直接注入 `PmFolderMapper` 写；`PmDocService` 单向依赖 `PmProjectService` 取可见性。
- **rbac 三段链在本仓的真实形态**：`pm:*` 码只存在于 Java `PermissionCatalog` + `sys_permission`；前端**不镜像码字符串**（`permissions.ts` 只有角色清单 `PM_VIEW_ROLES`）。`docs/40`「三处同改必含 permissions.ts」与实现**有偏差**，以实际实现为准。
